# Inteligência Documental

O Sherlocker permite busca full-text em documentos públicos, diários oficiais e publicações governamentais. Diferente das consultas estruturadas por CPF/CNPJ, aqui você trabalha com **texto livre**.

## Endpoint

<Card title="Busca textual" icon="magnifying-glass" href="/api-reference/documentos/buscar-em-fontes-publicas">
  `GET /documentos/busca?query={termo}`
</Card>

## Fontes cobertas

- **DOSP** — Diário Oficial de São Paulo (`source: "DOSP"`, `type: "Diário Oficial de São Paulo"`)
- **PJE** — Diário Judicial via Comunica PJe (`source: "PJE"`, `type: "Diário Judicial"`)

## Como usar

### Busca por nome

```bash
GET /documentos/busca?query=JOAO SILVA SANTOS
```

Retorna publicações onde o nome aparece — nomeações, exonerações, licitações, sanções, publicações de editais.

### Busca por CNPJ/CPF

```bash
GET /documentos/busca?query=12345678000199
```

Encontra publicações oficiais mencionando o documento.

### Busca por tema

```bash
GET /documentos/busca?query=licitacao prefeitura campinas pavimentacao
```

Busca textual livre por assunto.

## Interpretando resultados

Cada resultado (`results[]`) contém:

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `type` | string | Rótulo legível do tipo: `Diário Oficial de São Paulo` ou `Diário Judicial` |
| `title` | string | Título do documento |
| `description` | string | Resumo/seção; no PJe traz Tribunal, Órgão e Classe |
| `text` | string | Trecho do conteúdo com o contexto da menção |
| `link` | string | URL do documento original |
| `names` | array | Nomes vinculados — cada item tem `name` e `type` (`Mencionado` ou `Advogado`) |
| `date` | string\|null | Data da publicação. Sempre `null` para a fonte PJE |
| `source` | string | Fonte: `DOSP` ou `PJE` |

## Quando usar

A busca documental é especialmente útil para:

- **Nomeações e exonerações** — cargos públicos
- **Licitações** — participação em processos licitatórios
- **Sanções** — penalidades aplicadas por órgãos públicos
- **Publicações oficiais** — qualquer menção em diários oficiais
- **Complementar investigação** — encontrar informações que não aparecem nas consultas estruturadas
