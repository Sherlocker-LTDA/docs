Uma **Parte** representa uma pessoa física ou jurídica envolvida em um processo judicial.

## Campos

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `nome` | string | Nome da parte (Title Case) |
| `documento` | string | CPF ou CNPJ formatado; string vazia (`""`) quando ausente |
| `polo` | string | Polo capitalizado (`Ativo`, `Passivo`, `Terceiro`, `Outro`) |
| `tipo` | string | `Pessoa Física`, `Pessoa Jurídica` ou `Autoridade` |

## Exemplo

```json
{
  "nome": "João Silva de Oliveira",
  "documento": "123.456.789-01",
  "polo": "Ativo",
  "tipo": "Pessoa Física"
}
```

## Polos

| Polo | Descrição |
|------|-----------|
| `Ativo` | Quem inicia a ação (autor, exequente, reclamante) |
| `Passivo` | Contra quem a ação é movida (réu, executado, reclamado) |
| `Terceiro` | Parte interessada que ingressa no processo |
| `Outro` | Demais participantes |

<Note>
  No endpoint `GET /processos/numero/{numero}` as partes têm formato diferente:
  `documento` pode ser `null`, `polo` vem em minúsculas (`ativo`, `passivo`) e
  `tipo` é o slug bruto (`pessoa_fisica`, `pessoa_juridica`).
</Note>
