Este exemplo cria um Dossiê e acompanha seu processamento. O mesmo padrão — criar,
guardar o identificador e consultar o recurso — também aparece em Rastro e Lente.

## Antes de começar

Você precisa de uma chave `slhk_` com `dossies:write` para criar e
`dossies:read` para consultar. Veja [Autenticação](/plataforma/autenticacao).

## 1. Crie o Dossiê

```bash
curl -X POST https://221b-api.sherlocker.com.br/api/v1/dossies \
  -H "Authorization: Bearer slhk_sua_chave_aqui" \
  -H "Idempotency-Key: 123e4567-e89b-42d3-a456-426614174000" \
  -H "Content-Type: application/json" \
  -d '{
    "document": "52998224725",
    "subject_type": "cpf",
    "kind": "basic"
  }'
```

A resposta `202 Accepted` contém o `id` do Dossiê e seu estado atual. Guarde esse
identificador; ele será usado nas próximas consultas.

## 2. Consulte o andamento

```bash
curl https://221b-api.sherlocker.com.br/api/v1/dossies/{dossie_id} \
  -H "Authorization: Bearer slhk_sua_chave_aqui"
```

Enquanto o trabalho estiver em andamento, respeite `poll_after_seconds`. Pare as
consultas quando o estado for terminal e interprete o resultado junto com a
cobertura. Veja [Ciclo de vida e resultados](/plataforma/estados-resultados).
