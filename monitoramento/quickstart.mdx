## Antes de começar

Você precisa de uma chave `slhk_` com `monitors:write` para criar e alterar um
acompanhamento e `monitors:read` para consultá-lo.

## 1. Crie o Monitoramento

```bash
curl -X POST https://221b-api.sherlocker.com.br/api/v1/monitors \
  -H "Authorization: Bearer slhk_sua_chave_aqui" \
  -H "Idempotency-Key: 123e4567-e89b-42d3-a456-426614174000" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Fornecedor principal",
    "identifier": "52998224725",
    "identifier_type": "cpf",
    "listen_items": ["debts", "processes"],
    "frequency_hours": 24
  }'
```

A resposta `201 Created` contém o `id`, a situação, a saúde e a assinatura do
acompanhamento. Guarde o identificador retornado.

## 2. Consulte a situação atual

```bash
curl https://221b-api.sherlocker.com.br/api/v1/monitors/{monitor_id} \
  -H "Authorization: Bearer slhk_sua_chave_aqui"
```

Use `status`, `health` e `execution_allowed` em conjunto. Um Monitoramento ativo
pode estar temporariamente degradado sem ter sido pausado.

## 3. Consulte as mudanças detectadas

```bash
curl "https://221b-api.sherlocker.com.br/api/v1/monitors/{monitor_id}/changes?status=open" \
  -H "Authorization: Bearer slhk_sua_chave_aqui"
```

A coleção usa cursor. Quando `page.has_more` for `true`, envie
`page.next_cursor` na próxima consulta.

## 4. Reconheça uma mudança tratada

```bash
curl -X POST https://221b-api.sherlocker.com.br/api/v1/monitors/{monitor_id}/changes/{change_id}/ack \
  -H "Authorization: Bearer slhk_sua_chave_aqui"
```

Reconhecer não apaga a mudança; apenas registra que ela já foi tratada.
