**Status HTTP:** `500`

## O que significa

Ocorreu um erro inesperado no servidor ao processar a requisição. Não é um problema na sua requisição.

O campo `instance` carrega o `request_id` da chamada (`/v1?request_id=<id>`), que permite localizar o erro nos logs do servidor. O mesmo `request_id` também é ecoado no header de resposta e pode ser definido por você via header opcional `x-request-id` (se ausente, o servidor gera um UUID).

## Causas comuns

- Falha interna transitória no processamento da requisição.
- Indisponibilidade momentânea de um componente interno da API.

## Como corrigir

- Refaça a requisição com back-off exponencial. Em `POST /v1/analyses` e `POST /v1/operations`, reenvie com a **mesma** `Idempotency-Key`: assim não há risco de cobrança dupla se a requisição original tiver sido processada.
- Se o erro persistir, acione o suporte em [/support](/support) informando o valor de `instance` (ou o `request_id`).
- Para facilitar o suporte, envie o header `x-request-id` com um identificador do seu sistema em todas as chamadas.

## Exemplo

```json
{
  "type": "https://docs.sherlocker.com.br/problems/server_error",
  "title": "Internal Server Error",
  "status": 500,
  "code": "server_error",
  "detail": "An unexpected error occurred.",
  "instance": "/v1?request_id=req-uuid-here"
}
```

O texto de `detail` varia conforme a causa.
