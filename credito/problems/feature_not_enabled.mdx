**Status HTTP:** `403`

## O que significa

Uma feature obrigatória não está habilitada para o workspace. A API `/v1` do Motor de Crédito está em beta e o acesso é liberado por workspace, pela feature `analysis_engine` — a mesma que libera o Motor de Análise:

| Feature | Quando é exigida |
|---|---|
| `analysis_engine` | Qualquer chamada à API `/v1`, incluindo `POST /v1/operations` e `GET /v1/operations/{id}`. |

A resposta inclui o campo extra `request_access_url`, apontando para a página de solicitação de acesso.

## Causas comuns

- Workspace ainda sem acesso ao beta da API (`analysis_engine` desabilitada).
- Chave de API de um workspace diferente do que teve o acesso liberado.

## Como corrigir

- Acesse a URL em `request_access_url` ([Solicitar acesso](/credito/acesso)) e solicite o acesso à feature citada no `detail`.
- Confirme que a chave de API pertence ao workspace que recebeu a liberação.
- Em caso de dúvida, acione o suporte em [Suporte](/credito/suporte).

## Exemplo

```json
{
  "type": "https://docs.sherlocker.com.br/problems/feature_not_enabled",
  "title": "Feature Not Enabled",
  "status": 403,
  "code": "feature_not_enabled",
  "detail": "The analysis_engine feature is not enabled for this workspace. To request access visit https://docs.sherlocker.com.br/api/access or contact support at https://docs.sherlocker.com.br/support.",
  "request_access_url": "https://docs.sherlocker.com.br/api/access",
  "instance": "/v1?request_id=req-uuid-here"
}
```

## Campos extras

| Campo | Tipo | Descrição |
|---|---|---|
| `request_access_url` | string | URL da página de solicitação de acesso ao beta. |
