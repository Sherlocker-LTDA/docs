**Status HTTP:** `422`

## O que significa

A API não conseguiu resolver uma engine de borderô utilizável para a operação. A resolução segue esta ordem:

1. `engine_id` informado no body: precisa existir, pertencer ao workspace (ou ser template do sistema), estar ativa e ter blocos ativos.
2. `engine_id` omitido: usa a engine template de borderô do sistema.

Quando a engine encontrada não pode ser usada — arquivada, incompatível com a operação ou **sem nenhum bloco ativo** — ou quando nenhuma etapa resolve uma engine, a API retorna `422 no_engine`.

<Note>
  `engine_id` inexistente ou de outro workspace retorna [`404 not_found`](/credito/problems/not_found), não `422 no_engine`.
</Note>

## Causas comuns

- `engine_id` de uma engine **arquivada**.
- Engine de borderô com todos os blocos desativados (nada para avaliar).
- Engine incompatível com a operação (ex.: `subject_type` errado nos blocos de entidade).
- Workspace sem engine de borderô e sem template do sistema aplicável.

## Como corrigir

- Confira o `engine_id` enviado: ele deve ser o UUID de uma engine de borderô ativa do seu workspace, com ao menos um bloco ativo.
- Se não precisa de uma engine específica, omita `engine_id`: a API usa a engine template de borderô do sistema.
- Engines são criadas e configuradas no app Sherlocker (não há CRUD de engines pela API `/v1`). Verifique a configuração no app.
- Se a configuração parece correta e o erro persiste, acione o suporte em [Suporte](/credito/suporte).

## Exemplo

```json
{
  "type": "https://docs.sherlocker.com.br/problems/no_engine",
  "title": "Unprocessable Entity",
  "status": 422,
  "code": "no_engine",
  "detail": "No bordero engine is available for this operation.",
  "instance": "/v1?request_id=req-uuid-here"
}
```

O texto de `detail` varia conforme a causa.
